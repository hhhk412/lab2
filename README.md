## Описание проекта
Программа представляет собой графическую анимацию построения знаменитого фрактала «Папоротник Барнсли» с использованием системы итерируемых функций (алгоритм Chaos Game). Отрисовка выполняется на чистом Python с помощью графической библиотеки tkinter. Код проекта подвергнут рефакторингу и разделен на логические модули для улучшения читаемости и масштабируемости.

## Функциональные возможности

### Основной функционал
- Динамическая пошаговая отрисовка структуры фрактального листа
- Использование кастомной неоновой палитры для отображения точек
- Вывод интерактивного счётчика нарисованных точек в реальном времени

### Дополнительный функционал (Управление)
- **Пробел (Space)** — приостановить / возобновить анимацию
- **Клавиша R** — мгновенный сброс и запуск отрисовки заново

## Требования к системе
- **Python:** 3.12 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** Используются только стандартные встроенные пакеты Python (`tkinter`, `random`).

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd lab2
```

### 2. Создание и активация виртуального окружения
* **Windows (PowerShell):**
  ```bash
  python -m venv .venv
  .venv\Scripts\Activate.ps1
  ```
* **macOS / Linux:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка dependencies
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
* **Пробел** — Пауза/Старт.
* **R** — Перезапуск.

## Структура проекта
```text
lab2/
├── .venv               # Виртуальное окружение
├── .gitignore          # Настройки скрытия служебных файлов для Git
├── README.md           # Документация проекта
├── config.py           # Конфигурационные параметры интерфейса и графики
├── fractal.py          # Математическая логика расчета координат фрактала
├── main.py             # Точка входа, инициализация окна и цикл анимации
└── requirements.txt    # Список зависимостей проекта
```

**Назначение основных модулей:**
- `config.py` — хранит константы приложения: размеры окна, цветовые палитры, коэффициенты масштабирования и параметры скорости анимации.
- `fractal.py` — содержит изолированную функцию вычисления координат следующей точки папоротника Барнсли на основе вероятностных коэффициентов.
- `main.py` — главный файл программы: отвечает за сборку интерфейса, привязку горячих клавиш ввода и пошаговый рендеринг элементов на холсте.
